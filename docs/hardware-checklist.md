# 接続後の実機確認

更新日: 2026-10-12。

## 今回の確認結果（2026-10-12）

対象はDeckLink HD Extreme 3Dと、認識・出力開始を修正した未配布の本体／アドオンのローカルビルド。既存の0.3.0配布パッケージをそのまま試した結果ではない。

- VTR-PONの設定で機器を認識し、HDMI出力を有効にできた。
- HDMI 1080p60でInnoView INVPM001へサンプル動画を送出し、利用者が映像表示と約19秒の再生中に動き・黒い点滅や乱れがないことを確認した。
- SDIからの映像出力も利用者が確認した。SDIの受信機種・信号形式は今回の記録では特定していない。
- 以上を今回の基本映像出力の実機確認完了とする。音声・厳密A/V同期、入力、フィル／キー合成と物理同期、障害復帰、他出力との同時使用、長時間運用・他機種・別PC導入は追加確認として残す。
- 同じHDMIモニターで1080p30が無信号となった条件は未解決。1080p60の合格と分けて扱い、全形式の対応を確認したとはしない。

旧機種のPersistentIDがない場合はTopologicalIDを選択キーに使う。カードを移設・交換した場合は再選択する。送出開始は音声プリロールの開始・終了とSDK設定オブジェクトの保持を修正した。SDK 16.0を使うアドオンの通常buildと関連CTest 6/6に成功したが、自動テストの結果と上記の利用者による実画面確認は区別する。

修正を含むパッケージの再生成、チェックサム・配布先・対応ソース案内の更新は未実施。

## 追加確認に使う手順

以下は2026-10-01に作成した確認手順。上で確認済みとした範囲以外の合格記録ではない。

1. Desktop Video 16.4 導入後の Windows 再起動を済ませる。Desktop Video Setup で機器名、各チャンネル、入出力プロファイル、端子を確認する。
2. 導入済みのVTR-PON 3.0.0-beta.1を起動する。設定 → DeckLink の未接続表示が解消され、入力プルダウンで機器・CH・端子を選べることを確認する。
3. SDI／HDMI の信号を入力し、プレイリストへ追加する。サムネイル、エディット、オンエアの映像と左右音声を確認する。映像・音声の同時利用で二重キャプチャーを開始しないことを確認する。
4. 1080p29.97／59.94 など、実際の信号に合う形式で確認する。自動検出非対応の場合は入力形式を指定する。形式変更、信号断、復帰、チャンネル切替、再起動後の保存済み入力を確認する。
5. 出力チャンネルと映像形式を選び、DeckLink 出力を有効にする。受信モニターで信号形式、上下方向、色、縦横比、インターレースを確認する。オンエアの DSK・フェード・黒出力と、ミックス後の左右音声が一致することを確認する。
6. UVC／NDI と同時出力し、それぞれを個別に ON／OFF する。DeckLink 側の未接続・使用中・非対応形式で他の出力が継続することを確認する。フルスクリーン非表示時も確認する。
7. 入出力同時利用は機器の全二重プロファイルで確認する。片方向専用プロファイルのエラーが明確であることを確認する。
8. 機器未接続で本体を起動し、登録項目・設定を保持して通常操作できることを確認する。対応する接続方式で切断・再接続を試し、再検出と復帰を確認する。
9. 実際に見て聞いて映像・音声同期を確認する。長時間送出、負荷、終了、再起動を確認する。模擬テストを実信号の確認に置き換えない。
## フィル／キー

- 通常映像・フィル・キーを個別にオン／オフし、別々の物理出力へ割り当てられること。
- フィル／キーに同じ映像形式を指定し、対応機器では共通リファレンスを接続すること。同期再生中／個別再生中の表示と理由を確認すること。
- 外部スイッチャーのキー入力へ Key、フィル入力へ Fill を接続し、Straight／Premultiplied を外部機器側の合成設定と揃えること。
- DSK、半透明素材、フェード、FTB、透明縁を実映像で確認すること。Key の黒＝透明、白＝不透明、FTB の完了でフィル／キーが黒になること。
- 通常映像とフィルの音声、Key の無音を確認すること。受け側で同じ音声を重複して混ぜないこと。
- リファレンス喪失、ペア片側の抜線・障害でペア停止・再試行し、通常映像・入力・UVC／NDI が継続すること。
- 再接続、長時間のフレーム整合・遅延・A/V 同期は未確認。個別再生の物理同期は保証しない。
