# DeckLink 入出力の境界

2026-10-01。映像・音声経路まで実装済み。実機確認は未実施です。

| 所属 | 責務 |
| --- | --- |
| 本体 | 入力チャンネル選択、プレイリスト・入力共有、GStreamer 接続、最終合成映像の非同期 D3D11 readback、設定と状態表示 |
| 別配布アドオン | SDK、COM/MTA、機器・論理サブデバイス・端子の列挙、形式検出、キャプチャー、映像変換、ハードウェア送出 |
| C ABI | 固定幅整数と UTF-8。診断 ABI 1、media ABI 1、追加の output ABI 1。Qt／STL／SDK オブジェクトを渡さない |
| Desktop Video | 別途導入する公式ドライバー・Runtime・機器設定ソフト |

## 出力

```text
最終オンエア映像（DSK・フェード・黒出力を含む）
  ├─ 主表示
  ├─ 返しモニター
  ├─ UVC（仮想カメラ）専用経路
  ├─ NDI 専用経路
  └─ DeckLink 専用 readback → 有限キュー → MTA worker → SDK

最終ミックス音声 → NDI と DeckLink へ個別に分岐
```

DeckLink は UVC の NV12・共有領域・固定30fps経路を経由しません。描画側は3枚の staging texture を `DO_NOT_WAIT` で読み、待機しない publication に渡します。機器操作、スケーリング、SDK 色変換、音声変換・送出は worker で行います。DeckLink の障害は主表示の描画失敗へ伝播させません。

出力形式は機器モードの解像度・有理数フレームレートを使用します。BGRA 非対応時は SDK による UYVY 変換を使います。映像・音声は共通の単調増加する100ns時刻から機器時刻へ対応させ、約3フレームの先行キューに送ります。入力不足時は直前の映像と無音を送ります。現在の対応は最大4096×2160、8bit映像、48 kHz・2ch音声です。HDR・10bit・8K は対象外です。

本体・GPU を共有する追加出力です。SDK のプロセス分離や GPU 負荷の完全隔離を意味しません。映像方向・色・インターレース・音声同期・長時間動作は実機で確認します。

## 入力

永続機器 ID・論理サブデバイス・端子・形式を `decklink://ID/SUB/CONNECTION/MODE` に保存します。機器の列挙順だけで再接続しません。

同じ入力に対する映像・オンエア音声・エディット音声の購読は、本体の一つのキャプチャー worker を共有します。SDK コールバックは有限キューへコピーし、worker が各 appsrc へ渡します。購読解除は UI を待たせず、SDK 終了は所有する MTA worker で行います。入力形式変更はコールバックから通知し、owner worker が Stop／Enable／Flush／Start を行います。

機器不在を正常な列挙結果として扱い、設定・登録項目を消しません。出力は再検出後に保存済み選択で再開を試みます。入力は本体の共有入力管理が未接続表示・再試行を行います。ドライバー不在や ABI 不適合は機器不在と区別します。

## 配布

配置は `decklink-addons/vtr-pon-decklink-addon.dll`、ID は `vtr-pon-decklink-addon`、契約は `decklink-media-abi-v1`。Addon Package v2 のローカル導入・更新・削除に登録しました。SDK／Runtime／テスト DLL を含めず、本体のビルドやインストーラーから分離しています。
## フィル／キーと同期

通常映像・フィル・キーごとに有効フラグ、永続チャンネル ID、モードを保持します。従来の `outputChannel`／`outputMode` は通常映像の割当として引き継ぎます。未接続でも割当を削除しません。同じ物理サブデバイスを複数出力へ割り当てることを拒否します。

同じ GPU フレームから通常映像と透過合成映像を一括 readback し、一つの有限キュー・世代・100ns 時刻で渡します。フィル／キーの画像を両方作ってから送信し、キーは合成アルファを白黒へ展開します。フィルは premultiplied のまま、またはゼロアルファを黒にして straight へ変換します。形式不一致とペア片側障害では両側を停止します。通常映像・入力へ障害を伝播しません。

アドオンの `vtrpon_decklink_get_output_api(1)` は40バイトの追加 C ABIです。既存 media ABI 1（96バイト）・StreamOptions（32バイト）を変更しません。`openGroupedOutput` は先行バッファを用意して開始を保留し、`startGroup` が全メンバーの所有スレッド・グループ・映像形式・時刻を確認して一度だけ SDK 再生を開始します。グループ設定は終了時に以前の値へ戻します。

SDK の同期再生対応と共通リファレンスのロックを確認します。同じ DeckLink 8K Pro カード内のサブデバイスだけは SDK の内部同期例外を使います。非対応・未ロックの専用結果 `SyncUnavailable=6` に限り個別再生へ切り替え、画面へ非同期の理由を表示します。その他の SDK エラーはフォールバックせずペアを停止します。同期再生中のリファレンス喪失もペア停止・再試行の対象です。個別再生は共通ソースフレーム・時刻を維持しますが物理出力の位相を保証しません。

同期条件は [公式 SDK 同期再生ガイド](https://sdk-doc.blackmagicdesign.com/decklink-sdk/HighLevel/synchronized.html#synchronized-playback) に従います。機器プロファイル・端子割当・同期信号・外部スイッチャー設定・実際のフィル／キー整合は実機確認が必要です。
